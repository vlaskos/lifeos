# LifeOS focus

Chooses this week's focus in Goals & Streams.

## Find LifeOS
Read the "LifeOS Guide" page (data source ids, WIP limit, focus max = 3).
No Guide → offer `lifeos-setup` and stop.

## Steps
1. Read streams: In progress, Planned, and those with Weekly focus checked.
   Show a short picture: "In progress 5/4 (over the limit), focus last week: A, B, C."
2. If In progress > WIP limit: ask which ones to move back to Planned or Parking
   (multi-select). Do this before choosing focus.
3. Last week's focus: for each, ask Keep / Done / Drop from focus.
4. Pick new focus up to 3 total (multi-select from In progress + Planned;
   suggest ones with near deadlines first). Moving a Planned stream into focus
   also sets it In progress — only if it stays within the WIP limit.
5. For every focus stream without a Next step, ask for one:
   "One verb, 30 minutes or less." Offer 2 suggestions as quick choices + "My own".
6. Apply: Weekly focus checkbox, Status changes, Next step. Read back to verify.
7. Summary in 3 lines: focus list with next steps.
