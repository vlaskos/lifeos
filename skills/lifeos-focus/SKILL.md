# LifeOS focus

Chooses this week's focus in Goals & Streams.

## Find LifeOS
Read the "LifeOS Guide" page (data source ids, focus max = 3).
No Guide → offer `lifeos-setup` and stop.

Use field and option names from the Guide's **Names** section. The English names in
this skill are keys, the dashboard may use another language. No Names section =
English names.

## Steps
1. Read streams: In progress, Planned, and those with Weekly focus checked.
   Show a short picture: "In progress: 5, focus last week: A, B, C."
2. Last week's focus: for each, ask Keep / Done / Drop from focus.
3. Pick new focus up to 3 total (multi-select from In progress + Planned;
   suggest ones with near deadlines first). Moving a Planned stream into focus
   also sets it In progress.
4. For every focus stream without a Next step, ask for one:
   "One verb, 30 minutes or less." Offer 2 suggestions as quick choices + "My own".
5. Apply: Weekly focus checkbox, Status changes, Next step. Read back to verify.
6. Summary in 3 lines: focus list with next steps.
